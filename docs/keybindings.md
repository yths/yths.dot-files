# Keybindings

An overview of every keyboard binding configured by this setup, grouped by tool. The block
below is generated by [`helper/list_keybindings.py`](../helper/list_keybindings.py) (run
`python helper/gendocs.py` to refresh it) by statically parsing the configs under
`configuration/`.

The configured tables are exhaustive for bindings the configs declare literally. Two things
the parser cannot read from the files are summarised from curated knowledge instead:

- **qtile's loop-generated families** — the per-monitor group/screen chords and VT switches
  are built in `for` loops, so they are described as a family rather than enumerated.
- **Upstream tool defaults** — vim, tmux, and qutebrowser each ship hundreds of default
  bindings that stay active; the relevant ones are noted with a pointer to the tool's own
  reference rather than copied in full.

| `Super + s` | `chord → Switch focus to screen` | Switch focus to screen using subscript characters |
| `Super + f` | `chord → Switch to group` | Switch to group using subscript characters |
| `Super + d` | `chord → Move to group` | Move to group using subscript characters |

Generated families (6 templated bindings the config builds in loops, one set per connected monitor):

- **VT switching** — `Ctrl + Alt + F1` … `F7` switch to virtual terminals 1–7 (Wayland backend only).
- **`Super + s` → switch screen focus** — then `j` / `k` / `l` / `;` (one per monitor) focuses that screen.
- **`Super + f` → switch group** — then `j` / `k` / `l` / `;` jumps to a group on the active screen.
- **`Super + d` → move to group** — then `j` / `k` / `l` / `;` moves the focused window to that group.

qtile has no built-in default keybindings beyond what this config defines, so the table above is exhaustive for static bindings.

### vim (`configuration/vim/.vimrc`)

| Command | Keys | Maps to |
| --- | --- | --- |
| `map` | `<C-h>` | `<C-w>h` |
| `map` | `<C-j>` | `<C-w>j` |
| `map` | `<C-k>` | `<C-w>k` |
| `map` | `<C-l>` | `<C-w>l` |
| `nmap` | `<C-f>` | `:NERDTreeFind<CR>` |

These override a handful of bindings; vim's hundreds of built-in defaults (`i` insert, `:w` write, `dd` delete line, `/` search, `gg` / `G` jump, `u` undo, …) remain active. Full list: `:help index`.

### tmux (`configuration/tmux/tmux.conf`)

Prefix: `C-b` (tmux default — not overridden here).

| Keys | Command |
| --- | --- |
| `C-b r` | `source-file ~/.config/tmux/tmux.conf \; display "::: tmux config reloaded :::"` |
| `C-b C` | `new-window -c "#{pane_current_path}"` |

tmux ships an extensive default key table that stays active, e.g. `C-b c` new window, `C-b %` / `C-b "` split, `C-b d` detach, `C-b [` copy mode, `C-b ,` rename window. Full list: the *DEFAULT KEY BINDINGS* section of `man tmux`.

### qutebrowser (`configuration/qutebrowser/config.py`)

| Keys | Command |
| --- | --- |
| `td` | `config-cycle colors.webpage.darkmode.enabled true false` |
| `,M` | `hint links spawn mpv {hint-url}` |
| `,m` | `hint links spawn mpv --fs {hint-url}` |

Only the explicit overrides above are added; qutebrowser's full default keymap stays active, e.g. `o` / `O` open, `f` hint, `H` / `L` back / forward, `gt` tab select, `/` search, `:` command mode. Full list: <https://qutebrowser.org/doc/help/configuring.html> and `:bind` in the browser.

> rofi and xorg configure action names and the keyboard layout rather than discrete shortcuts, so they are not listed here. The rofi window switcher (`Super + Shift + r`) prefixes each entry with its group as `[N]`; groups map to screens in blocks of four (groups 1–4 → screen 1, 5–8 → screen 2, …), so the prefix doubles as a screen hint.
