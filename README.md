## Getting Started

Clone this repository and run the `install.py` script.

```bash
git clone https://github.com/yths/yths.dot-files.git
yay -S python-screeninfo
python install.py
```

## Dependencies

* [IPinfo](https://ipinfo.io/) an API access token of this service is required to translate the (external) IP address into geolocation data (required to determine sun rise and sun set to trigger automated dark/light theme switch accordingly)
