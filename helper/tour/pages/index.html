One palette, every surface

A staged page: what the browser shows in the repository's screenshots.

A desktop is a dozen programs that each want their colours in a format of their own. The usual answer is a dozen themes that drift apart. This one keeps a single palette and derives the rest: the bar, the terminal, the launcher, the notifications, the login screen and the boot splash all read the same nine tokens.

Patchers

Each application has one patcher that writes the palette into that application's own configuration format. A patcher holds no colours; it knows only where its application wants them. Two applications ship far more colours than anyone would name by hand, so theirs are matched instead: every stock colour is replaced by the nearest token in a perceptual colour space.

Switching

At sunrise and sunset the palette's other half is applied and the running programs are told. Nothing restarts that a person would notice, apart from the bar redrawing.
